# AI Island V0.1 产品需求文档

版本：0.1.1 · 日期：2026-09-15 · 状态：开发基线（加入多项目和软件抽屉）

## 1. 产品定位

Windows 桌面顶部的轻量悬浮胶囊。用户在 CMD、PowerShell、Windows Terminal 中使用 Codex / Claude Code 时，自动展示 AI 的任务状态、计时和完成提醒。

**运行中指 AI 正在思考或执行任务，不是 CLI 进程存在。** CLI 打开但等待输入时保持收缩；单次回答完成后收缩，不要求退出 CLI。

## 2. V0.1 范围

- C# / .NET 8、WPF、Win32，无 Electron、数据库、网络服务、账号。
- 深色半透明圆角胶囊，顶部居中、置顶、不占任务栏、不抢焦点、可点击、阴影。
- Codex / Claude Provider，支持同 Provider 多会话，同时独立计时。
- 单击展开详情：Provider、状态、本次任务开始时间、耗时、会话 ID、可获取时的 PID。
- 右键及托盘：显示、设置、暂停/恢复监控、退出。双击定位 Terminal 延后。
- 设置：Provider 开关、顶部左/中/右、开机启动（默认关）、完成提醒、动画。
- 支持左键自由拖动，松手记住位置；单击与拖动通过移动阈值区分。自定义位置跨重启保存，限制在显示器工作区；选择顶部预设可复位。
- 本地 JSON 保存设置；无对话内容持久化。

## 3. 信号与架构

进程轮询（1000ms）仅用于在线检测，不推断思考状态。任务状态优先由 CLI 官方生命周期 Hook 提供。接入需一次性配置，保留原有用户 Hook，可卸载；配置前备份。

Provider 将各 CLI 信号转为 IslandEvent，经过进程内 EventBus → 状态服务 → WPF。Hook 桥接仅保留 Provider、会话 ID、事件种类、时间、可获取时的进程标识；丢弃提示词、回答和工具参数。通信使用本地文件事件收件箱，不监听网络端口。

Codex 活动轮次可使用 Hook 提供的记录路径补偿缺失结束事件：只核对首条会话身份及匹配 turn_id 的 task_complete / turn_aborted 元数据，限制读取大小和频率，不存储对话。非稳定格式无法识别时保持原 Hook 行为，不从历史记录新增或恢复活动任务。

未接入 Hook 时只能显示“在线 / 未接入任务状态”，不能误报 Running。旧 CLI 缺少必要事件时明确提示升级或不支持。程序重启不能凭进程存在恢复任务状态，等待下一个可信事件。

## 4. 状态机

会话状态：Online / Offline。任务状态：Idle / Thinking / Executing / WaitingForApproval / Completed / Failed / Ended。

| 信号 | 状态 / 行为 |
|---|---|
| 会话启动 | 在线，胶囊保持收缩 |
| 提交任务 | Thinking，重置本次计时，展开 |
| 工具开始 | Executing，保留任务计时 |
| 工具结束 | Thinking，不判定整项任务完成 |
| 请求权限确认 | WaitingForApproval |
| 本次响应结束 | Completed，冻结计时，展示约 3 秒 |
| 明确任务错误 | Failed，冻结计时，展示约 3 秒 |
| 会话退出且任务未完成 | Ended，不猜测成功失败 |
| 结束展示到期 | Idle，若无其他任务则收缩 |

“思考中”是任务处理中状态，不读取或判断模型内部推理。总耗时从提交开始，含工具执行及等待确认。工具失败不直接代表整个任务失败。中断与无法确认结果显示已结束。

## 5. 多会话与边界

- 使用 Provider + SessionId 区分会话；进程使用 PID + 启动时间防止 PID 复用。
- 一个任务完成不影响其他任务，结束项单独保留 3 秒。
- 新任务覆盖该会话旧完成展示，不被旧定时器收缩。
- 重复/乱序事件不得倒退状态；忽略不支持事件与损坏输入。
- 暂停时明确展示暂停，停止状态展示更新；恢复后从新信号重建，不伪造完成。
- 详情面板限制高度并支持滚动。定位适应工作区和 DPI。
- 退出释放托盘、计时器及事件接收资源，CLI 不受影响。

## 6. 视觉与动画

展开与收起均固定宽 420 DIP（含两侧阴影留白），顶部位置保持不动，仅向下展开；底部空间不足时限制抽屉高度并滚动。深黑底、柔和描边、绿色/蓝色活动点、完成绿色、失败红色、等待琥珀色。展开约 280–360ms，内容延迟淡入；收起约 360ms，高度平滑加减速，内容淡出与收缩同时进行，不先留下空面板再骤缩。禁用动画时立即切换。

## 7. 性能与隐私

目标空闲 CPU <1%、工作集 <100MB（需注明硬件并实测，非预先保证）。限制事件文件大小、处理批量和状态保留数量，及时清理已处理事件；不记录对话、不发网络请求、不影响 CLI 退出码。

## 8. 验收

1. 启动程序：顶部小胶囊、托盘可用、任务栏无图标。
2. CLI 仅打开：不显示思考中。
3. Codex/Claude 提交任务：收到 Hook 后 1 秒内展开计时。
4. 回答结束但 CLI 未退出：完成约 3 秒后收缩；下一次提交重新计时。
5. 工具执行、权限等待可区分；仅工具错误不误报任务失败。
6. 同时运行两个 CLI / 两个同类会话：独立展示计时与完成。
7. 暂停/恢复、Provider 开关、设置保存、位置及动画开关有效。
8. 畸形/重复/乱序事件不崩溃、不覆盖更新状态。
9. Exit 完全退出，重新运行正常；CLI 不受影响。
10. 完成真实 CLI 人工验收与性能测量后才宣布 V0.1 验收完成。

## 9. 后续路线

V0.2 Windows 通知聚合、微信/钉钉通知；V0.3 使用量与统计；V0.4 自定义 Provider / 事件 / 插件；V1.0 桌面事件中心。EventBus 预留消息与通知事件，本版不读取微信/钉钉内容、不统计 Token/费用、不管理 API Key。

## 10. 实施顺序

PRD → 核实官方 Hook 与本机 CLI → 任务状态核心和测试 → Hook 桥接与配置工具 → WPF 胶囊/详情/托盘/设置 → 编译及事件链路验证 → 真实 CLI 和视觉性能验收。

## 11. V0.1.1 已确认增量（优先于上文同类旧行为）

- AI 自动展示区与手动工具抽屉独立：任一任务开始，自动展示全部已监控会话；全部任务结束且结果展示 3 秒后恢复数量摘要。标题点击和岛外点击仅控制 QQ 音乐、Clash 操作，不隐藏活动 AI。仅标题可拖动，手动工具不因 AI 结束自动收起。
- AI 按 Provider 分组、按 SessionId 独立展示项目；项目目录取首次有效 cwd，不推断 Git 根目录。旧事件显示未知项目，同名目录加父路径，同目录多会话加唯一短标识。
- 完成 3 秒后在线会话显示等待输入，空闲时隐藏耗时，下一轮重新计时；确认退出后移除在线行。无法确认进程存在时标明连接未知。
- QQ 音乐主程序运行时显示歌曲、歌手、上一首、播放/暂停、下一首、打开应用；只使用属于 QQ 音乐的系统媒体会话，按能力禁用按钮。不做音量、进度条、歌词。
- Clash Verge 主程序运行时显示 Windows 实际系统代理开关及打开应用；使用 WinINet，保留代理绕过项与地址，冲突时禁用操作，不修改 Verge 内部配置。不做 TUN、模式、节点。
- AI 模块常驻，其他模块随软件出现/消失，可独立禁用；共享进程发现约 1 秒，AI 收件箱独立 500ms，不被媒体查询阻塞。内置 IIslandModule 扩展接口，无插件市场、外部脚本或网络监听服务。
- 抽屉宽约 420 DIP，高度上限工作区 70%，超出滚动；始终向下展开，底部空间不足时滚动，保留原拖动坐标兼容性。

## 12. 接入可见性与操作闭环
- 各 Provider 接入状态以本次运行实际收到的有效事件为依据，展示最近事件时间、未收到、禁用或暂停；不将历史收到信号等同当前在线。
- 等待确认持续琥珀色突出展示，进入连续等待阶段时提醒一次；失败红色、完成绿色。
- 项目名点击尝试返回可靠关联的控制台/终端窗口，详情箭头保留；无法定位显示原因，多标签页不承诺自动选中。


## 13. 可撤回的增强轮廓
默认 EnhancedOutline=true，背景 #252B38、边框 #76839A、悬停 #B4C6DF。运行淡蓝光晕，等待琥珀色，失败淡红色；状态切换轻亮一次，不循环闪动。原版模式恢复背景 #F018191E、边框 #FF34363F、黑色阴影（模糊14、偏移3、透明度0.35），无增强悬停和光晕。设置可保存并恢复，固定尺寸和交互不变。
