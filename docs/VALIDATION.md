## 接口限制

- Hook 对应客户端版本的真实事件发出情况仍需上述验收，不能只凭最新文档与合成事件宣布兼容。
- Stop Hook 可被其他 Hook 要求继续；后续任务/工具事件会重新展开。它表示本次响应停止，不代表代码或用户目标必然成功。
- 权限批准没有统一后置事件时，“等待确认”会在下一个工具/任务事件到来后更新。
- Codex 未配置明确任务失败 Hook；中断及进程丢失显示 Ended，不能猜成 Failed。
- 进程祖先关联受进程权限和启动方式影响；不能关联且收不到结束事件时需暂停/恢复清理。
- V0.1 不读取终端输出或聊天记录，不覆盖原有 Hook 返回值，不干预 AI CLI 决策。
- QQ 音乐只控制其系统媒体会话；客户端未提供会话时降级显示，不能宣称所有版本都支持。
- Clash 控制 Windows 系统代理，不修改 Verge 内部状态；Verge 重新应用设置时卡片回读反映变化。标准用户配置目录不可用、PAC、其他代理或代理守卫冲突会禁用开关。未做 TUN 或模式操作。
